# SkyBook Airlines

A simple **airline booking system** built with **HTML, CSS, and JavaScript**. Search flights, add passenger details, select seats, make dummy payments, and view bookings.

## Features

* Sign Up & Login
* Search flights by source, destination, and date
* Enter passenger details
* Seat selection
* Dummy payment page
* View previous bookings after login

## How to Use

1. Open `index.html` in a browser (Live Server recommended).
2. Sign up and login.
3. Search flights and click **Book**.
4. Enter passenger details, select a seat, and pay.
5. Click **My Bookings** on Home to view your reservations.
